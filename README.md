Bounty: [news-image-20261119](https://make.fun/bounty/news-image-20261119)

## How it works

`main.ts` (Node 22, standard library only) copies `entry.png` — the rendered front page beside it — to `$MAKEFUN_OUTPUT_DIR/entry.png` (or `/output/entry.png`). Deterministic: two runs write byte-identical output.
